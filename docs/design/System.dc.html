Design system · v1

TWO INKS

Every decision has two sides, so the interface has two inks. Denim always means THIS, marigold always means THAT, and nothing else in the product uses either colour. Everything else is ink on cool paper, so the split is always the loudest thing on screen. Labels borrow from election-night results desks: margin, n, too close to call.
