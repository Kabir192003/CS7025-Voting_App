# Redesign docs

- `case-study/This-or-That-Case-Study.pdf`: the redesign case study, covering the audit, research, design decisions, visual system, backend plan, question set and sources. `case-study.html` is its source.
- `design/`: source of the redesign canvas, made in Claude Design with seven artboards: Feed, Poll detail, Ask, Profile, Mobile feed, Onboarding and the Two Inks system sheet. The `.dc.html` files are Design Component pages that run inside the Claude Design editor; `canvas.json` holds the layout.

The app code in this repo is unchanged. The redesign will be built from these files.
